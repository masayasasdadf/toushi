# 📈 カブナビ — 初心者のための株式投資判断サポート

株式投資の初心者が「迷わない」「大失敗しない」ことに特化した投資判断サポートツールです。

## できること

| 機能 | 内容 |
|---|---|
| **総合判定** | 6つのテクニカル指標(移動平均・RSI・MACD・ボリンジャーバンド・出来高・トレンドの勢い)を統合し、「強い買いシグナル〜購入禁止」の5段階で一つの結論を表示 |
| **判定の根拠** | 各指標を初心者向けの日本語で解説。なぜその判定なのかが分かる |
| **AI解説** | Claude APIが分析結果を初心者向けにかみ砕いて解説し、「今とるべき行動」を提示 |
| **損切りライン自動計算** | ATR(値動きの大きさ)から推奨損切りラインと利益目標を自動算出 |
| **ポジションサイズ計算** | 資金と許容リスクから「何株まで買っていいか」を計算。初心者の大損の最大の原因である「買いすぎ」を防止 |

対応銘柄:日本株(証券コード4桁、例 `7203`)・米国株(ティッカー、例 `AAPL`)

## ⚠️ 大事なこと

**「絶対に間違わない」投資ツールは存在しません。** このツールは、統計的に優位性があるとされるテクニカル分析のルールと、プロが必ず守るリスク管理(損切り・ポジションサイズ)を初心者でも実践できるようにしたものです。判定どおりに売買しても損失が出ることはあります。必ず余裕資金で、損切りルールを守って使ってください。

## Vercelへのデプロイ手順

1. このリポジトリをGitHubにpush(済み)
2. [vercel.com](https://vercel.com) にGitHubアカウントでログイン
3. **Add New → Project** からこのリポジトリ(`toushi`)をインポート
4. **Environment Variables** に以下を追加(AI解説機能を使う場合):
   - `ANTHROPIC_API_KEY` = [Claude Console](https://platform.claude.com/) で取得したAPIキー
5. **Deploy** をクリック

数分でデプロイ完了し、`https://あなたのプロジェクト名.vercel.app` で使えるようになります。

> APIキーを設定しなくても、テクニカル分析・リスク計算は動作します(AI解説のみ無効)。

## ローカルでの開発

```bash
npm install
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env.local  # AI解説を使う場合
npm run dev
# http://localhost:3000
```

## 技術構成

- **Next.js 14**(App Router)+ TypeScript — Vercelにゼロ設定でデプロイ可能
- **株価データ**: Yahoo Finance 公開チャートAPI(サーバーサイドで取得、5分キャッシュ)
- **AI**: Anthropic Claude API(`claude-opus-4-8`、アダプティブ思考有効)
- 外部チャートライブラリ不使用(SVGで軽量描画)
